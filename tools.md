# Tools

Small utilities, web services, and minor tools that don't warrant their own paper.

## 🔍 Find Software Alternatives

* [**AlternativeTo**](https://alternativeto.net/) – Crowdsourced platform to find software alternatives.
* [**Osalt**](https://osalt.com/) – Open source alternatives to commercial software.

## 🌐 Network Utilities

* [**IP Location**](https://www.iplocation.net/) – Geolocation lookup based on IP address.

## ➗ Math & Encoding

* [**Hexator**](https://hexator.com/) – Number system converter and calculator.
* [**Base64 Encode**](https://www.base64encode.org/) – Online base64 encoder/decoder.

## 🖼️ Photo Editing (lightweight)

* [**Remove.bg**](https://www.remove.bg/) – AI background removal.
* [**Pixlr**](https://pixlr.com/) – Online photo editor.
* [**Paint.NET**](https://www.getpaint.net/) – Lightweight image editor for Windows.

## ✂️ Video Editing (lightweight)

* [**CapCut**](https://www.capcut.com/) – Simple video editor for social content.
* [**Shotcut**](https://shotcut.org/) – Cross-platform open-source video editor.
* [**GarageBand**](https://www.apple.com/mac/garageband/) – Music production for macOS.

## 🧱 3D (lightweight)

* [**Spline**](https://spline.design/) – 3D design tool for the web.
* [**Rumba**](https://www.rumba-animation.com/) – Character animation software.

## 🧾 Office (alternatives)

* [**WPS Office**](https://www.wps.com/) – Lightweight office suite alternative.

## 🛡️ Security (lightweight)

* [**Windows Security**](https://support.microsoft.com/en-us/windows/microsoft-defender-antivirus-frequently-asked-questions-2f64fae1-b7c3-3d0c-6036-2f20cf63f6b6) – Built-in Windows antivirus.
* [**VirusTotal**](https://www.virustotal.com/) – Online malware scanning for files and URLs.

## ✅ Productivity (lightweight)

* [**PDF-XChange Editor**](https://www.tracker-software.com/product/pdf-xchange-editor) – Feature-rich PDF editor.
* [**7-Zip**](https://www.7-zip.org/) – File archiver with high compression.
* [**LanguageTool**](https://languagetool.org/) – Multilingual grammar and style checker.
* [**Grammarly**](https://www.grammarly.com/) – AI writing assistant for English.
* [**Codeium**](https://codeium.com/) – AI-powered autocomplete plugin for editors.

## 🛠️ System Utilities (lightweight)

* [**Revo Uninstaller**](https://www.revouninstaller.com/) – Thorough uninstallation utility.
* [**WizTree**](https://diskanalyzer.com/) – Fast disk space analyzer for Windows.
* [**WhySoSlow**](https://www.resplendence.com/downloads) – Performance analyzer for system bottlenecks.
* [**PCUsageViewer**](https://github.com/mtalhi/PCUsageViewer) – Monitor computer usage history.

## 📱 Social Networks

* [**X (Twitter)**](https://x.com/) – Social media platform for real-time news and discussion.

## 🤖 AI Utilities (lightweight)

* [**ccusage**](https://github.com/ryoppippi/ccusage) – Token usage and cost tracking for Claude Code and other agent CLIs.
* [**RTK**](https://github.com/rtk-ai/rtk) – CLI proxy that compresses bash output before it reaches the LLM.
* [**Caveman Claude**](https://github.com/amanattar/caveman-claude-skill) – Claude skill for terse responses to cut output tokens.
