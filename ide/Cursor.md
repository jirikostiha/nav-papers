## Tutorials

### Integrating Codex, Claude Code, and Antigravity in Cursor

Cursor provides seamless integration options for AI development tools and agentic workflows:

- **OpenAI Codex**: Configure OpenAI API keys and custom model providers within Cursor settings (`Settings > Models`)
  or run Codex CLI tools in the integrated terminal.
- **Claude Code**: Execute Claude Code agent CLI (`claude`) directly within Cursor's embedded terminal
  to perform automated codebase refactoring and search.
- **Google Antigravity**: Connect Google Antigravity agentic workflows, custom MCP servers, and workspace rules
  within Cursor projects to orchestrate autonomous coding tasks.
